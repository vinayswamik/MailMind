# MailMind

I built **MailMind** — an iOS app that signs into **Gmail**, pulls your mail, and helps you **see what matters sooner**: categories, summaries, and a calmer inbox-style flow instead of drowning in unread noise.

**Why it’s useful:** your mail stays **yours**. Sign-in and Gmail access go through Google’s APIs; processing leans on **on-device** work where it fits, so you get a smarter triage experience without handing your whole inbox to a random web dashboard.
